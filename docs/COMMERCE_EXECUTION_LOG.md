## 停止/回滚与剩余风险

- 停止本地 runner 即关闭该入口；正常站点没有开启模式，返回 404。没有生产数据库迁移。本地迁移是新增表，不回填展示目录；撤销功能时保留库存历史，不做破坏性降级。
- 当前只支持未支付测试订单。取消和内部到期命令拒绝处理 `processing/unknown`，不能假定这些订单可安全释放。支付成功、迟到事件、退款、通知、对账和运营 Admin 均未完成。
- **没有自动到期清理任务**。页面明确要求手动取消以释放测试库存；最新 20 笔之外的订单和 Cookie 丢失恢复尚无 UI。下一次 runner 使用新临时数据库，旧目录保留。支付接入前必须补齐期限调度和恢复策略。
- 目录商品列表最多 200 个，但报价按确切 ID 查找，不再错误拒绝第 201 个变体。完整商业商品后台、存量目录迁移不在本批。
- 旧 Admin 改价格/数量在启用商业变体时由 DB 拒绝，尚未提供经营者友好的商业编辑界面；虚构本地阶段可接受，营业前必须完成。
- 本地接口没有生产限流、正式访客身份/保留/隐私机制。禁止公开代理这个端口；不能简单修改环境开关上线。
